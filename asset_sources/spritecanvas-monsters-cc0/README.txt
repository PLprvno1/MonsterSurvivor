SpriteCanvas fantasy monsters (CC0)

Four monsters with five moves each: idle, walk, attack, hurt and death. Every move is a PNG sprite
sheet with a JSON Hash atlas (Phaser load.atlas, PixiJS Assets). All moves of a monster share the
same cell size and foot pivot, so they swap without jumping. Monsters face left; flip them for the
other side. Each folder has a README with frame counts, cell size, fps and the pivot.

- slime, mushroom, goblin, golem: idle (loop), walk (loop), attack, hurt, death
