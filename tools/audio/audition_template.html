Cách dùng và lưu kết quả cho Task 05.1B

Mở AUDIO_AUDITION.html bằng Edge hoặc Chrome trên Windows. Giữ HTML ở gốc project và thư mục asset_sources/audio/ tại vị trí hiện tại. Manifest đã nhúng trong HTML; không dùng mạng, server hay fetch. Không chuyển riêng HTML sang thư mục khác.

Tìm tên file hoặc lọc nguồn ở mỗi event, chọn một dòng, bấm ▶ Nghe thử, rồi ✓ Chọn âm thanh này. Duyệt/nghe không tự lưu lựa chọn. Candidate cũ chỉ là gợi ý, không tự duyệt; event MISSING cũng có đầy đủ thư viện. Nhiều event có thể dùng chung file.

Lựa chọn được lưu trong trình duyệt nếu localStorage khả dụng. Hãy xuất monster-survivor-audio-selections.json để giữ bản chắc chắn và chuẩn bị cho Task 05.1B. JSON luôn chứa cả 49 event, gồm event_id, file_path tương đối từ gốc project và status (selected/unselected). Nhập JSON để tiếp tục; chỉ những event có trong JSON được cập nhật, các event còn lại giữ nguyên. Bản xuất cũ 05.1A cũng được hỗ trợ; lựa chọn im lặng cũ được chuyển về chưa chọn file.

Thời lượng lấy từ lần quét/giải mã file, không cần tải trước hàng trăm âm thanh. File preview của pack không thuộc danh sách SFX/BGM. Khi thêm audio, chạy python tools/build_audio_audition.py để quét lại và cập nhật cả HTML lẫn AUDIO_AUDITION_MANIFEST.json. Đây là công cụ lựa chọn, chưa tích hợp audio vào game.

Không có event phù hợp bộ lọc.
